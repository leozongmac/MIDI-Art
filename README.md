# AKAI MPK mini 星空粒子钢琴可视化

一个浏览器端的 Web MIDI + Web Audio + Canvas 交互程序：

- 连接 **AKAI MPK mini** 之类的 MIDI 键盘
- 按下琴键时触发内置钢琴采样
- 用音符、力度、Pitch Bend、CC1/Mod Wheel 驱动一幅梵高《星空》风格的粒子艺术画面
- 形成粒子扩散、涟漪、旋涡与星光脉冲效果
- 支持页面内实时调节：**粒子数量、粒子寿命、引力效果、弹射效果**
- 支持用户**上传自己的图片**并转换成粒子画
- 支持**本地摄像头实时画面**作为粒子底图
- 支持**全屏舞台模式**，可隐藏操作界面仅保留粒子画面
- 支持 **MIDI 延音（CC64 Sustain）**

## 文件结构

- `index.html`：页面结构
- `style.css`：界面样式
- `app.js`：MIDI、音频、粒子渲染逻辑
- `assets/starry_night_particles_source.png`：粒子画源图
- `assets/samples/*.wav`：内置钢琴采样

## 运行方式

> Web MIDI 通常需要在 **localhost / HTTPS** 环境中运行，直接双击 `index.html` 可能无法读取 MIDI 设备。

### 方式 1：Python 本地服务器

在当前目录执行：

```bash
python3 -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

### 方式 2：VS Code Live Server

如果你用 VS Code，可以直接用 Live Server 打开项目。

## 使用说明

1. 连接 AKAI MPK mini
2. 用 Chrome 或 Edge 打开页面
3. 点击 **“启动音频与 MIDI”**
4. 浏览器会请求 MIDI 权限，允许即可
5. 开始弹奏
6. 通过左上角的滑块调整视觉效果
7. 点击顶部 **“上传图片”** 或左侧上传区，选择自己的图片后，粒子画会立即重建
8. 也可以直接把图片**拖拽到上传区域**完成替换
9. 点击 **“启动摄像头”** 可把底图切换成实时摄像头画面
10. 点击 **“全屏模式”** 可隐藏操作界面并进入纯粒子舞台画面
11. 通过 **图片阈值** 滑块控制图片被提取成粒子的密度门槛
12. 点击 **“恢复默认”** 可以切回默认《星空》图像

## 控制映射

- **琴键 Note On/Off**：触发钢琴采样与粒子涟漪
- **Velocity**：决定涟漪强度、亮度与爆发感
- **Pitch Bend**：影响弯音与画面轻微偏转
- **CC1 / Mod Wheel（或映射到 CC74）**：增强粒子扰动和旋涡
- **CC64 Sustain**：支持延音踏板逻辑
  - 踩下踏板后，抬起琴键不会立刻断音
  - 松开踏板时，未继续按住的音符会统一释放
- **图片上传**：把任意 PNG / JPG / WebP 等图片转换为粒子底图
- **拖拽上传**：可直接把图片拖到左侧上传区域
- **摄像头模式**：把本地摄像头实时画面转换为动态粒子底图
- **全屏模式**：隐藏控制界面，仅保留粒子效果画面
- **图片阈值**：控制图像中哪些区域更容易被保留为粒子

## 无 MIDI 时测试

可以直接用电脑键盘：

- 音符：`A W S E D F T G Y H U J K`
- 延音测试：按住 `Space`
